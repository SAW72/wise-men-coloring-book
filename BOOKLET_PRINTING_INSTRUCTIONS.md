# Booklet Printing Instructions

## Wise Men Coloring Book

**File:** `Wise_Men_Coloring_Book.pdf`

### Simple Print
- Print the 9-page PDF single-sided or double-sided on letter/A4 paper.
- Best on white cardstock for durability while coloring.

### Booklet Option (half-letter)
1. Print double-sided (flip on short edge).
2. Fold sheets in half (or use a booklet printer setting if available).
3. Staple along the fold.
4. Enjoy the pocket-sized Magi coloring book!
